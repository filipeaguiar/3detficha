## ADDED Requirements

### Requirement: Visual mana cost indicator for modifier buttons
The system SHALL display the mana cost of a modifier button using a slanted rectangular graphic that matches the style of the existing mana bar.

#### Scenario: Display mana cost visually
- **WHEN** a modifier button is rendered in the UI
- **THEN** the button shall show a slanted rectangle indicating its mana cost, with the appropriate number of rectangles proportional to the cost value.
